4. 법인세 상당액

입력 내용을 확인한 뒤 결과 페이지로 이동합니다.

입력 가이드

금액은 모두 원 단위 정수로 입력하세요.
  • 영업이익: 세무조정 전 금액입니다. 조정액은 3번에 따로 입력하세요.
  • 총매출: 해당 사업연도 전체 매출액
  • 특수관계자 세부매출: 거래처별 매출을 표에 입력합니다. 거래가 없으면 0으로 두세요. 거래처가 많으면 엑셀 업로드로 한 번에 채울 수 있습니다 — 양식을 받아 금액만 채우거나, 회계·ERP 파일을 그대로 올려도 됩니다.
  • 세무조정내역: 가산은 양수, 차감은 음수 (예: -3500000)
  • 법인세 상당액: 세후영업이익에서 차감됩니다.
세후영업이익 = 영업이익 ± 세무조정금액 − 법인세 상당액
법인·기업 구분과 지분 데이터는 서버에 보관된 값을 사용하며 화면에서 수정할 수 없습니다.
